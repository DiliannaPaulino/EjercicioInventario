
# Sistema de Inventario para una Tienda de Barrio

## 1. Integrantes que elaboraron el programa

- Dilianna Alicia Paulino Nolasco.

## 2. Descripción del programa

Una tienda de barrio necesita un programa de consola para llevar el control del inventario de sus productos. En este ejercicio se hará uso de listas, métodos y condicionales dentro de los métodos, con el propósito de registrar, organizar y mostrar la información de los productos.

## 3. Entrada

Los datos que el usuario introduce al programa son:

- Nombre del producto.
- Precio del producto.
- Opción del menú que desea ejecutar.

## 4. Proceso

El programa realiza los siguientes procesos:

- Registrar productos en una lista.
- Almacenar la información de cada producto.
- Mostrar los productos registrados.
- Calcular promedios.
- Utilizar métodos para organizar las operaciones.
- Aplicar condicionales para controlar las opciones del menú y las acciones del programa.

## 5. Salida

El programa muestra en consola:

- Lista de productos registrados.
- Nombre y precio de cada producto.
- Cantidad de determinados productos, según la operación realizada.
- Resultados de las operaciones y estadísticas.
- Mensajes de confirmación o advertencia.
- Mensaje de finalización: "Hasta luego".

## 6. Tecnologías aplicadas

- **Lenguaje de programación:** C++.
- **Entorno de desarrollo:** Visual Studio Community.
- **Estructura de datos:** Listas.
- **Elementos de programación:** Métodos y condicionales.
- **Tipo de aplicación:** Programa de consola.
